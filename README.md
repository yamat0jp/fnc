# fnc

＊Free Epub Reader


epubjsを用いた無料の電子書籍リーダー。

コード内にはepubjsの公開されているファイルを含みます。

使われているTMS FNCコンポーネントは有償物を使わせていただいております。

コンパイルしたい方はTMSのウェブページからご購入ください。



旧バージョンでは内部にBiBiを使わせていただいておりましたがサーバー機能の

取り外し目的でepubjsに利用変更いたしました。

読み込めるファイルもファイルサイズの小さい文書EPUBに限られました。

ご利用くださる皆様にはご迷惑おかけしますが機能が不足と感じられる場合には

ほかの有償サービスのご利用を検討してください。



＊インストール・アンインストール


解凍ファイルを単一のフォルダに移して、.EPUBの既定のアプリとして設定してください。

設定-アプリ-既定のアプリで変更可能になります。うまくいかないときはプログラムから

開く-常に使う、でも設定ができます。

この作業をしておくとEPUBファイルをダブルクリックで利用開始です。

アンインストールの際には他の電子書籍リーダーを利用される場合には先ほどと同様の手順で

利用を継続されるソフトウェアを設定したうえで、フォルダごと本ソフトウェアを削除してください。
